# Contributing

Thanks for helping! A few ground rules keep this project useful and lawful:

- **No copyrighted material.** Don't add, link to, or describe where to find games, firmware, keys or other people's
  copyrighted files. Issues and pull requests that do are closed and deleted.
- **No piracy features.** Cartridge works only with files the user already has. It won't download, share or decrypt
  content itself; building is done by [nxnative](https://github.com/seedds/nxnative).
- **No third-party trademarks or artwork in the repo.** Use the fictional games in `Scripts/screenshots.sh` for
  screenshots, and fictional names and IDs in tests.
- Keep the app native: SwiftUI, system fonts and SF Symbols, standard macOS behaviour.

Run `swift test` and `Scripts/build.sh` before opening a pull request.
